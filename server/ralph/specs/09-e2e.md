# 명세 09 — 흐름 E2E S1~S6 (단계 9, 프런트 화면 완성 뒤)
바탕: docs/scenarios.yaml, 03-delivery.md 3-4, 키트 `e2e/`.

## 결정
- `e2e/`는 키트를 복사한 독립 패키지(루트 workspaces에 넣지 않음). spec은 `e2e/scenarios/S<n>.spec.ts`, 파일마다 test 하나.
- `page.goto`는 창마다 1회(로그인 화면 예외). `test.skip`·`page.route`류 금지. 상대 경로만.
- 버튼·메뉴 이름은 실제 화면과 같아야 하며, 다르면 scenarios.yaml과 spec을 같은 커밋에서 고친다(프런트 팀원과 합의).
